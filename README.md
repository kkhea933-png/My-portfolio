# My Portfolio

A personal portfolio built with React and Vite.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Notes

This project showcases my work, skills, and contact information in a clean single-page portfolio layout.

## GitHub Pages

The `main` branch deploys to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.
In the repository settings, set **Pages** > **Build and deployment** > **Source** to **GitHub Actions**.
